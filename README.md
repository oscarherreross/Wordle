# Wordle
Juego de adivinanza de palabras multijugador en Java Swing con arquitectura MVC. Jugador 1 introduce una palabra; Jugador 2 intenta adivinarla completando casillas con letras (máximo 8 intentos). Sistema de puntuación decreciente, ranking de mejores jugadores e interfaz con menús, imágenes de victoria/derrota y gestión completa de eventos.
